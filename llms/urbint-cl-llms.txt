# Urbint Component Library (@urbint/cl) - LLM Documentation

> This documentation is designed for LLM consumption to assist developers using the Urbint Component Library.

## Overview

Urbint Component Library (`@urbint/cl`) is an enterprise-ready React Native component library built with Unistyles 3.0. It provides 40+ production-ready components for B2B SAAS applications across iOS, Android, and Web platforms.

**Key Features:**
- Cross-platform: iOS, Android, Web
- Full TypeScript support
- Light and Dark themes
- Accessible (WCAG 2.1 compliant)
- Built with Unistyles 3.0

**Tech Stack:**
- React Native 0.81+
- Unistyles 3.0+
- TypeScript 5.0+
- Expo SDK 54+

---

## Installation

```bash
# Install the library and peer dependencies
npm install @urbint/cl react-native-unistyles

# Or with yarn
yarn add @urbint/cl react-native-unistyles

# Or link locally during development
npm link ../path-to-urbint-cl
```

### Babel Configuration

Add the Unistyles Babel plugin to `babel.config.js`:

```javascript
module.exports = function (api) {
  api.cache(true);
  return {
    presets: ['babel-preset-expo'],
    plugins: [
      ['react-native-unistyles/plugin', { root: 'src' }],
    ],
  };
};
```

### Setup

Import styles in your app entry point before any components:

```tsx
// App.tsx
import '@urbint/cl/styles';
import { Box, Text, Button } from '@urbint/cl';

export default function App() {
  return (
    <Box p="lg">
      <Text>Hello World</Text>
      <Button variant="primary">Click Me</Button>
    </Box>
  );
}
```

#### Select
Dropdown selection with popover-style dropdown. Supports single select, multi-select, and searchable modes with hover states.

```tsx
import { Select } from '@urbint/cl';

// Basic usage
<Select 
  label="Country"
  placeholder="Select country"
  options={[
    { value: 'us', label: 'United States' },
    { value: 'uk', label: 'United Kingdom' },
    { value: 'ca', label: 'Canada' },
  ]}
  value={country}
  onChange={setCountry}
/>

// Multi-select
<Select 
  label="Technologies"
  placeholder="Select technologies..."
  isMultiple
  options={[
    { value: 'react', label: 'React' },
    { value: 'vue', label: 'Vue' },
    { value: 'angular', label: 'Angular' },
  ]}
  value={selectedTechs}
  onChange={setSelectedTechs}
/>

// Searchable select
<Select 
  label="Country"
  placeholder="Search countries..."
  isSearchable
  searchPlaceholder="Type to search..."
  options={countryOptions}
/>

// Searchable multi-select
<Select 
  label="Tags"
  placeholder="Search and select tags..."
  isSearchable
  isMultiple
  noResultsText="No tags found"
  options={tagOptions}
/>

// With custom filter function
<Select 
  label="Technologies"
  isSearchable
  isMultiple
  options={techOptions}
  filterOption={(option, query) => 
    option.label.toLowerCase().includes(query.toLowerCase()) ||
    option.category?.toLowerCase().includes(query.toLowerCase())
  }
/>

// With custom option rendering
<Select 
  options={[
    { value: 'us', label: 'United States', flag: '🇺🇸' },
    { value: 'uk', label: 'United Kingdom', flag: '🇬🇧' },
  ]}
  renderOption={({ option, isSelected, isHovered, searchQuery }) => (
    <HStack space="sm" style={{ flex: 1 }}>
      <Text>{option.flag}</Text>
      <Text style={{ color: isSelected ? '#00A0CC' : '#000' }}>
        {option.label}
      </Text>

  renderSelectedValue={({ option, selectedOptions, placeholder, isMultiple }) => (
    option ? (
      <HStack space="sm">
        <Text>{option.flag}</Text>
        <Text>{option.label}</Text>
      </HStack>
    ) : (
      <Text style={{ color: '#9CA3AF' }}>{placeholder}</Text>
```

#### DatePicker
Date and time picker with multiple modes. Supports date only, time only, or date and time selection (side by side). Uses a `Modal`-based dropdown on iOS/Android. On web, consider using a native HTML `<input type="date|time|datetime-local">` for better browser integration (see "Cross-Platform Consumption" below).

```tsx
import { DatePicker } from '@urbint/cl';

// Date only
<DatePicker 
  label="Date of Birth"
  mode="date"
  placeholder="Select date"
  value={date}
  onChange={setDate}
/>

// Time only
<DatePicker 
  label="Appointment Time"
  mode="time"
  placeholder="Select time"
  use24HourFormat={false}
/>

// Date and time (side by side layout)
<DatePicker 
  label="Event Start"
  mode="datetime"
  placeholder="Select date & time"
  value={datetime}
  onChange={setDatetime}
  showNowButton={true}
/>

// With min/max constraints
<DatePicker 
  label="Future Date"
  mode="date"
  minDate={new Date()}
  maxDate={new Date(2026, 11, 31)}
/>

// With custom format
<DatePicker 
  label="European Format"
  mode="date"
  formatDate={(date) => {
    const d = date.getDate().toString().padStart(2, '0');
    const m = (date.getMonth() + 1).toString().padStart(2, '0');
    return `${d}/${m}/${date.getFullYear()}`;
  }}
/>

// 24-hour time format
<DatePicker 
  label="Time (24h)"
  mode="time"
  use24HourFormat={true}
/>

// Monday as first day of week
<DatePicker 
  label="Week starts Monday"
  mode="date"
  firstDayOfWeek={1}
/>
```

**Props:**
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| mode | 'date' \| 'time' \| 'datetime' | 'date' | Picker mode |
| value | Date | - | Controlled value |
| defaultValue | Date | - | Default value |
| onChange | (date: Date) => void | - | Change handler |
| placeholder | string | Auto-generated | Placeholder text |
| label | string | - | Label text |
| helperText | string | - | Helper text |
| errorMessage | string | - | Error message |
| isInvalid | boolean | false | Error state |
| isDisabled | boolean | false | Disable picker |
| isRequired | boolean | false | Required field |
| minDate | Date | - | Minimum selectable date |
| maxDate | Date | - | Maximum selectable date |
| size | 'sm' \| 'md' \| 'lg' | 'md' | Picker size |
| variant | 'outline' \| 'filled' | 'outline' | Visual variant |
| formatDate | (date: Date, mode: DatePickerMode) => string | Default formatter | Custom format function |
| use24HourFormat | boolean | false | Use 24-hour time format |
| firstDayOfWeek | 0 \| 1 | 0 | First day (0=Sunday, 1=Monday) |
| showNowButton | boolean | true | Show "Now" button in time/datetime modes |

**Mode Details:**
- `date`: Shows calendar only, closes on date selection
- `time`: Shows hour/minute/AM-PM columns with "Now" and "OK" buttons
- `datetime`: Shows calendar and time picker side by side with "Now" and "OK" buttons

**Controlled vs Uncontrolled:**
- **Controlled:** Pass `value` (a `Date`) and `onChange`. The component reflects the `value` you give it.
- **Uncontrolled:** Omit `value` (or pass `undefined`). Optionally pass `defaultValue` for an initial selection. Internal state manages the selected date.
- **Important:** Do NOT switch between controlled (`value={someDate}`) and uncontrolled (`value={undefined}`) across re-renders. Pick one pattern. If you need to clear a controlled value, manage a separate `hasValue` flag rather than toggling `value` between a `Date` and `undefined`.

**Cross-Platform Consumption (iOS / Android / Web):**

On **iOS and Android** the DatePicker component works directly and renders a native `Modal` with the calendar/time picker. On **web** the component also works, but you may prefer native HTML inputs for better browser integration. A common pattern is to branch by platform:

```tsx
import { Platform, View } from 'react-native';
import { DatePicker, HStack, Box, Pressable } from '@urbint/cl';
import { X } from 'lucide-react-native';

function DateTimeField({ value, onChange, onClear, label, mode }) {
  // Web: use native HTML inputs for best browser experience
  if (Platform.OS === 'web') {
    const inputType = mode === 'date' ? 'date' 
      : mode === 'time' ? 'time' 
      : 'datetime-local';

    return (
      <Box>
        <Text variant="caption" weight="semiBold">{label}</Text>
        <input
          type={inputType}
          value={value ?? ''}
          onChange={(e) => onChange(new Date(e.target.value))}
          style={{ padding: 12, borderRadius: 4, border: '1px solid #ccc' }}
        />
      </Box>
    );
  }

  // iOS / Android: use the DatePicker component
  return (
    <Box>
      <HStack alignItems="flex-end" space="sm">
        <View style={{ flex: 1 }}>
          <DatePicker
            label={label}
            mode={mode}
            value={value}
            onChange={onChange}
          />
        </View>
        {value && (
          <Pressable onPress={onClear} style={{ padding: 12 }}>
            <X size={18} color="#6B7280" />
          </Pressable>
        )}
      </HStack>
    </Box>
  );
}
```

**Full Real-World Example (form field with clear button):**

```tsx
import React, { useState } from 'react';
import { View } from 'react-native';
import { DatePicker, HStack, Box, Pressable, Text } from '@urbint/cl';
import { X } from 'lucide-react-native';

// Helper formatters
const formatDate = (date: Date) => {
  const m = String(date.getMonth() + 1).padStart(2, '0');
  const d = String(date.getDate()).padStart(2, '0');
  return `${m}/${d}/${date.getFullYear()}`;
};

const formatTime = (date: Date) => {
  let h = date.getHours();
  const min = String(date.getMinutes()).padStart(2, '0');
  const ampm = h >= 12 ? 'PM' : 'AM';
  h = h % 12 || 12;
  return `${String(h).padStart(2, '0')}:${min} ${ampm}`;
};

const formatDateTime = (date: Date) => `${formatDate(date)} ${formatTime(date)}`;

function MyDateTimeField() {
  const [selectedDate, setSelectedDate] = useState<Date | undefined>(undefined);

  const handleChange = (date: Date) => {
    setSelectedDate(date);
  };

  const handleClear = () => {
    setSelectedDate(undefined);
  };

  const formatForPicker = (date: Date, mode: 'date' | 'time' | 'datetime') => {
    if (mode === 'date') return formatDate(date);
    if (mode === 'time') return formatTime(date);
    return formatDateTime(date);
  };

  return (
    <Box>
      <HStack alignItems="flex-end" space="sm">
        <View style={{ flex: 1 }}>
          <DatePicker
            label="Event Date & Time"
            mode="datetime"
            value={selectedDate}
            onChange={handleChange}
            placeholder="MM/DD/YYYY HH:mm"
            isRequired
            formatDate={formatForPicker}
            showNowButton
          />
        </View>
        {selectedDate && (
          <Pressable onPress={handleClear} style={{ padding: 12, minHeight: 48, justifyContent: 'center' }}>
            <X size={18} color="#6B7280" />
          </Pressable>
        )}
      </HStack>
    </Box>
  );
}
```

**Key Consumption Notes:**
1. The `value` prop expects a `Date` object or `undefined`. Do not pass strings.
2. The `onChange` callback receives a `Date` object.
3. The `formatDate` prop signature is `(date: Date, mode: DatePickerMode) => string` — it controls how the selected value is displayed in the trigger.
4. For **controlled** usage, always pass `value` as a `Date` or keep it consistently `undefined`; avoid toggling between the two.
5. Wrap the DatePicker in a `View` with `flex: 1` when placing it inside an `HStack` so it takes available space.
6. The dropdown uses a `Modal` internally — it renders at the root level, so parent `overflow: 'hidden'` will not clip it.

#### Combobox
Autocomplete input with a dropdown list of suggestions. Supports async loading, custom item rendering, controlled/uncontrolled input, and cross-platform (iOS, Android, Web). Uses a Modal-based dropdown (same pattern as Select) to avoid overflow/zIndex issues.

```tsx
import { Combobox, ComboboxItem } from '@urbint/cl';

// Basic usage with local filtering
const [value, setValue] = useState('');
const [filtered, setFiltered] = useState(items);

const handleInputChange = (text: string) => {
  setValue(text);
  setFiltered(
    items.filter((item) =>
      item.label.toLowerCase().includes(text.toLowerCase())
    )
  );
};

<Combobox
  label="Framework"
  placeholder="Search frameworks..."
  inputValue={value}
  onInputChange={handleInputChange}
  items={filtered}
  onSelect={(item) => setValue(item.label)}
/>

// Async loading with search icon
const [query, setQuery] = useState('');
const [results, setResults] = useState<ComboboxItem[]>([]);
const [loading, setLoading] = useState(false);

const handleSearch = (text: string) => {
  setQuery(text);
  if (text.length < 2) { setResults([]); return; }
  setLoading(true);
  fetchResults(text).then((data) => {
    setResults(data);
    setLoading(false);
  });
};

<Combobox
  label="Location"
  placeholder="Search a city..."
  inputValue={query}
  onInputChange={handleSearch}
  items={results}
  isLoading={loading}
  onSelect={(item) => setQuery(item.label)}
  minChars={2}
  leftElement={<Icon name="search" />}
/>

// With error state
<Combobox
  label="Location"
  placeholder="Search..."
  items={[]}
  isInvalid
  errorMessage="Location is required"
/>

// Disabled
<Combobox
  label="Location"
  placeholder="Search..."
  items={[]}
  isDisabled
/>

// Custom item rendering
<Combobox
  items={users}
  renderItem={({ item, isHighlighted, searchQuery }) => (
    <HStack space="sm">
      <Avatar name={item.label} size="xs" />
      <VStack>
        <Text weight="semiBold">{item.label}</Text>
        <Text variant="caption">{item.description}</Text>
      </VStack>
    </HStack>
  )}
/>
```

**Props:**
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| items | ComboboxItem[] | required | Available items to display in the dropdown |
| inputValue | string | - | Controlled input value |
| onInputChange | (text: string) => void | - | Called when input text changes (for search/filtering) |
| onSelect | (item: ComboboxItem) => void | - | Called when an item is selected |
| placeholder | string | 'Search...' | Placeholder text |
| label | string | - | Label text above the input |
| helperText | string | - | Helper text below the input |
| errorMessage | string | - | Error message (replaces helperText) |
| isInvalid | boolean | false | Error state |
| isDisabled | boolean | false | Disable input |
| isReadOnly | boolean | false | Read-only input |
| isRequired | boolean | false | Required field |
| isLoading | boolean | false | Show loading spinner in dropdown |
| size | 'sm' \| 'md' \| 'lg' | 'md' | Input size |
| variant | 'outline' \| 'filled' | 'outline' | Input variant |
| emptyText | string | 'No results found' | Text shown when no items match |
| loadingText | string | 'Loading...' | Text shown while loading |
| leftElement | ReactNode | - | Left element (e.g. search icon) |
| rightElement | ReactNode | - | Right element (shown left of chevron) |
| renderItem | (props: RenderComboboxItemProps) => ReactNode | - | Custom render for dropdown items |
| closeOnSelect | boolean | true | Close dropdown on item select |
| maxDropdownHeight | number | 260 | Max height of the dropdown list |
| minChars | number | 0 | Minimum characters before showing dropdown |
| textInputProps | TextInputProps | - | Additional TextInput props |

**ComboboxItem:**
```ts
interface ComboboxItem {
  value: string;       // Unique identifier
  label: string;       // Display label
  description?: string; // Optional secondary text
  disabled?: boolean;  // Whether item is disabled
  [key: string]: any;  // Additional custom data
}
```

**RenderComboboxItemProps:**
```ts
interface RenderComboboxItemProps {
  item: ComboboxItem;
  isHighlighted: boolean;
  isDisabled: boolean;
  searchQuery: string;
}
```

**Controlled vs Uncontrolled:**
- **Controlled:** Pass `inputValue` and `onInputChange`. You manage the filtering and pass filtered `items`.
- **Uncontrolled:** Omit `inputValue`. The component manages internal input state. You still need to pass `items` (the component does not filter for you).

**Key Differences from Select:**
- Combobox has a text input for typing/searching; Select has a trigger button.
- Combobox is ideal for autocomplete, search-as-you-type, and async data fetching scenarios.
- Select is better for static, predefined option lists.

```tsx
</Accordion>

// Icon on left for all items
<Accordion iconPosition="left" defaultIndex={['item-1']}>
  <AccordionItem value="item-1">
    <AccordionButton>Site Conditions</AccordionButton>
    <AccordionPanel>
      <Text>Site conditions content...</Text>
    </AccordionPanel>
  </AccordionItem>
  <AccordionItem value="item-2">
    <AccordionButton>Activities</AccordionButton>
    <AccordionPanel>
      <Text>Activities content...</Text>
    </AccordionPanel>
  </AccordionItem>
</Accordion>

// Per-item icon position override
<Accordion iconPosition="right">
  <AccordionItem value="item-1">
    <AccordionButton iconPosition="left">Override to left</AccordionButton>
    <AccordionPanel>
      <Text>This item has icon on left.</Text>
    </AccordionPanel>
  </AccordionItem>
  <AccordionItem value="item-2">
    <AccordionButton>Uses default (right)</AccordionButton>
    <AccordionPanel>
      <Text>This item uses default position.</Text>
    </AccordionPanel>
  </AccordionItem>
</Accordion>
```

**Accordion Props:**
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| defaultIndex | string[] | [] | Initially expanded |
| allowMultiple | boolean | false | Multiple open sections |
| allowToggle | boolean | true | Allow toggling items |
| iconPosition | 'left' \| 'right' | 'right' | Position of expand/collapse icon for all items |
| onChange | (index: string[]) => void | - | Change handler |

**AccordionButton Props:**
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| iconPosition | 'left' \| 'right' | - | Override icon position for this button (inherits from Accordion if not set) |

## Theming

### Creating a Custom Theme

```tsx
// src/styles/customTheme.ts
import { lightTheme, darkTheme } from '@urbint/cl';

export const myLightTheme = {
  ...lightTheme,
  colors: {
    ...lightTheme.colors,
    brand: {
      primary: '#YOUR_PRIMARY_COLOR',
      secondary: '#YOUR_SECONDARY_COLOR',
    },
  },
};

export const myDarkTheme = {
  ...darkTheme,
  colors: {
    ...darkTheme.colors,
    brand: {
      primary: '#YOUR_DARK_PRIMARY',
      secondary: '#YOUR_DARK_SECONDARY',
    },
  },
};
```

### Configuring Themes

```tsx
// src/styles/unistyles.ts
import { StyleSheet } from 'react-native-unistyles';
import { myLightTheme, myDarkTheme } from './customTheme';

StyleSheet.configure({
  themes: {
    light: myLightTheme,
    dark: myDarkTheme,
  },
  settings: {
    adaptiveThemes: true, // Auto-switch based on OS preference
  },
});
```

### Switching Themes

```tsx
import { UnistylesRuntime } from 'react-native-unistyles';

// Get current theme
const currentTheme = UnistylesRuntime.themeName;

// Set theme
UnistylesRuntime.setTheme('dark');

// Toggle theme
const toggleTheme = () => {
  UnistylesRuntime.setTheme(
    UnistylesRuntime.themeName === 'light' ? 'dark' : 'light'
  );
};
```

## Best Practices

### Component Composition
```tsx
// ✅ Good - compose components with spacing tokens
<Card>
  <CardHeader>
    <HStack space="md">
      <Avatar name="John" />
      <VStack>
        <Text weight="semiBold">John Doe</Text>
        <Text variant="caption">Software Engineer</Text>
      </VStack>
    </HStack>
  </CardHeader>
  <CardBody>
    <Text>Content here</Text>
  </CardBody>
</Card>
```

### Form Handling
```tsx
// ✅ Good - use FormControl with spacing tokens
<VStack space="lg">
  <FormControl label="Name" isRequired>
    <Input value={name} onChange={setName} />
  </FormControl>
  
  <FormControl label="Email" isInvalid={!!emailError} errorMessage={emailError}>
    <Input value={email} onChange={setEmail} />
  </FormControl>
  
  <Button onPress={handleSubmit}>Submit</Button>
</VStack>
```

### Loading States
```tsx
// ✅ Good - show loading placeholders with spacing tokens
{isLoading ? (
  <HStack space="md">
    <SkeletonCircle size={48} />
    <VStack space="sm" flex={1}>
      <Skeleton height={16} width="60%" />
      <Skeleton height={14} width="40%" />

    <VStack>
      <Text weight="semiBold">{user.name}</Text>
      <Text variant="caption">{user.role}</Text>
    </VStack>
  </HStack>
)}
```

## TypeScript Support

All components are fully typed. Import types as needed:

```tsx
import type { 
  ButtonProps,
  InputProps,
  CardProps,
  ModalProps,
  ToastOptions,
  SpacingToken,  // Type for spacing tokens
  ComboboxProps,
  ComboboxItem,
  RenderComboboxItemProps,
} from '@urbint/cl';
```

### SpacingToken Type
The `SpacingToken` type represents all valid spacing token names:

```tsx
type SpacingToken = 
  | 'none' | 'xs' | 'sm' | 'md' | 'lg' | 'xl' | '2xl' | '3xl' | '4xl' | '5xl'
  | '0.5x' | 'base' | '2x' | '3x' | '4x' | '6x' | '8x' | '12x' | '18x';
```

Components that accept spacing (Box, HStack, VStack, Grid) use `SpacingToken | number` so you can use either tokens or raw pixel values.

```bash
# Clear cache and restart
npx expo start --clear
```

### Unistyles not working
1. Ensure Babel plugin is configured
2. Restart Metro bundler
3. Check import order (styles before components)

```tsx
// Make sure to import styles first
import '@urbint/cl/styles';

import { Button } from '@urbint/cl';
```

## MCP Server Integration

The Urbint Component Library includes an MCP (Model Context Protocol) server that enables AI assistants to discover and use the design system programmatically.

### Setup

```bash
# Install MCP server dependencies
npm run mcp:install

# Build the MCP server
npm run mcp:build
```

### Configure in Cursor IDE

Add to your Cursor MCP settings (`~/.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "urbint-cl": {
      "command": "node",
      "args": ["/path/to/urbint-cl/mcp-server/dist/index.js"]
    }
  }
}
```

### Available MCP Tools

| Tool | Description |
|------|-------------|
| `list_components` | List all components, optionally filter by category |
| `get_component` | Get detailed component documentation |
| `search_components` | Search components by name, description, or tags |
| `get_design_tokens` | Get design tokens (colors, spacing, etc.) |
| `search_tokens` | Search for specific design tokens |
| `generate_component_code` | Generate code snippets for components |
| `get_form_pattern` | Generate form pattern code with validation |
| `get_layout_pattern` | Generate layout pattern code |

### Example Usage

Once configured, ask your AI assistant:

- "List all form components in the Urbint design system"
- "Show me how to use the Select component with multi-select"
- "What colors are available in the design system?"
- "Generate a login form with email and password"
- "Show me a dashboard layout pattern"

### Available MCP Resources

- `urbint://docs/overview` - Library overview
- `urbint://docs/components` - All components
- `urbint://docs/tokens` - Design tokens
- `urbint://docs/installation` - Installation guide
- `urbint://component/{name}` - Individual component docs
